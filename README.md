# ScholarSprint

ScholarSprint is a responsive scholarship discovery and application-tracking product. It demonstrates client-side ranking, explainable match scores, profile-aware filtering, deadline visualization, persistent workflow state, CSV reporting, calendar export, and accessible interaction design.

## Run locally

Serve the `dist` directory with any static web server, for example:

```bash
python3 -m http.server 4173 --directory dist
```

Then open `http://localhost:4173`.

## Resume-ready highlights

- Built a responsive scholarship recommendation interface with explainable fit scoring and multi-dimensional filters.
- Implemented a persistent application pipeline with browser storage and workflow state transitions.
- Added standards-based CSV and iCalendar exports for interoperable reporting and deadline planning.
- Designed keyboard shortcuts, semantic controls, responsive layouts, and reduced-motion support for accessibility.

The bundled dataset is representative demo content. A production version can replace it with a verified scholarship feed or ingestion API.
